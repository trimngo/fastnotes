# Floating Memo
Independent Android app (dev.floatingmemo) for an always-on-top, movable, resizable transparent handwriting memo. Minimize to a bar. Local atomic stroke storage, multiple notes, undo and eraser. Grant display-over-other-apps permission. Experimental native ENote transparent layers are enabled by default, with Android fallback. Native ownership is released on minimize, move, resize, close or outside touch; use Fast toggle if another app needs the pen. Native overlay alignment and latency require AiPaper device validation. Build with root `./gradlew -p floating-memo :app:assembleDebug` or the Floating Memo APK workflow. No FastNotes app code or saved notes are changed.

## v0.2 Palm Lock
Tap Palm off in the toolbar to block touches across the app content behind the memo. The transparent host window expands to the available screen, while the memo stays movable and resizable. Palm ON is shown in inverse colors. Tap again, minimize, close, or turn the screen off to release; the notification also has a Close memo action. System bars and protected screens remain under Android control. Native pen is restarted after geometry changes. Device testing is still required. CI debug APK signatures may differ across independent runners; do not uninstall an existing copy containing notes without first backing them up.
